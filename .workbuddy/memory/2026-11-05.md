## gonglue-tai（游戏攻略大全 / 游戏攻略总站）

- 仓库：https://github.com/sdadsa424/gonglue-tai ，线上：https://sdadsa424.github.io/gonglue-tai/ （GitHub Pages，main 分支直出）
- 站点形态：单页门户 + 23 篇攻略数据驱动。暗色门户风，主色 `--pink #FF3D9A` / `--purple #8B5CF6`，三游戏色 `ejl #2DD4A7`、`xxtl #4C9AFF`、`ty #FF6B8A`。
- **架构（本次改造后）**
  - `assets/style.css`：全站唯一样式（首页与静态页共用）
  - `assets/data.js`：`GAMES / CATS / GUIDES` 唯一数据源，浏览器走全局、Node 走 `module.exports`
  - `index.html`：首页 SPA，只保留筛选/搜索/分站 hash 路由；攻略卡片指向真 URL `a/<id>/`
  - `a/<id>/index.html`：构建产物，**不要手改**
  - `build/build.mjs`：`node build/build.mjs` 生成 23 篇攻略页 + `sitemap.xml` + `robots.txt`，并向 index.html 的 `<!-- BUILD:HEAD -->` / `<!-- BUILD:NOSCRIPT -->` 标记注入首页结构化数据与无脚本目录
  - `tools/check.mjs`：本地内链 + 标签配对检查
- **改内容的正确姿势**：编辑 `assets/data.js` → `node build/build.mjs` → `node tools/check.mjs` → 提交推送
- 站点常量在 `build/build.mjs` 顶部：`SITE`、`UPDATED`、`CS`（客服号 ggboy6123）
