    先看结论

    • 纹章学者位置：普雷利镇伯恩施坦 / 魔法山脊盖尔 / 凯德拉关卡贝利 / 崇高之地斯塔西

    制作、镶嵌与升级

    • 制作 10% 概率出附加属性：四维、双攻、会心系、双防、生命法力、最终伤害中随机一条
    • 镶嵌无部位限制，大部分栏位随等级自动解锁，1 个专属栏位需特权解锁
    • 升级消耗纹章碎片 + 金币；品质越高等级上限与词条数越多
    • 分解多余纹章得纹章碎片——升级与洗炼的核心材料

    洗炼与词条锁定

    • 洗炼消耗：纹章碎片 + 金币 + 秘传纹章
    • 额外消耗高级纹章碎片可锁定优质词条，被锁词条不会被重置
    • 重要：洗炼会重置出「非当前天赋生效」的词条，洗之前先确认流派

    养成路线：前期制作镶嵌基础纹章囤碎片 → 中期升级到关键节点解锁词条 → 后期洗炼优化，用锁定功能保住毕业词条。优先保留适配自身天赋的技能词条。
